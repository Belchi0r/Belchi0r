I'm an **Engineering student at Universidade de Brasília (UnB)** focused on **Software Engineering and Full Stack development**.

I build web applications with attention to what happens beyond the UI: **architecture, business rules, databases, authentication, testing, security and deployment**. I like understanding a system end to end — from the browser to the database.

<table>
<tr>
<td width="55%" valign="top">

### Energy Monitor

Full Stack application for **residential energy-consumption estimation and analysis**.

It goes beyond the dashboard layer and includes:

- authentication and SSR sessions;
- layered architecture with Services and Repositories;
- PostgreSQL + Supabase persistence;
- historical snapshots per user and device;
- validation and access-control rules;
- dashboards, alerts and deterministic recommendations;
- **556 automated tests passing**;
- production deployment on Vercel.
